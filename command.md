Build a modern, production-ready full-stack e-commerce web application called "Spotless Beauty Lab".

## 🎯 Overview

This is a beauty and skincare e-commerce platform based in Ethiopia that sells authentic imported products from the USA and Korea, including skincare, hair care, cosmetics, and accessories.

The platform must support two roles:

1. Customers (public storefront)
2. Admin (private dashboard for business owner)

## 🎨 Design Requirements

* Ultra-modern 2026 UI/UX design
* Clean, minimal, luxury aesthetic (inspired by high-end beauty brands)
* Soft color palette (white, beige, soft pink, gold accents)
* Fully responsive (mobile-first)
* Smooth animations and transitions
* High-quality product cards and image galleries

## 🛍️ Customer-Facing Features

### Homepage

* Hero section with brand message ("Authentic Skincare from USA & Korea")
* Featured products section
* Categories (Skincare, Haircare, Accessories, etc.)
* Promotional banners (discounts, offers)
* Testimonials / reviews
* Trust badges (100% authentic, imported)

### Product Listing Page

* Grid layout
* Filters (category, price, brand, skin type)
* Sorting (price, popularity, newest)

### Product Detail Page

* Multiple product images
* Description, ingredients, usage
* Price and discount display
* Stock availability
* “Add to Cart” button
* “Buy Now” option
* Related products

### Cart Page

* Editable cart items
* Price breakdown
* Subtotal + total

### Checkout Page

* Customer details form
* Delivery information
* Payment options:

  * Telebirr integration
  * Cash on delivery
* Order confirmation page

### User Account (Optional but recommended)

* Order history
* Profile management

### Extra Features

* WhatsApp “Order Now” button
* Search functionality
* Reviews and ratings system

---

## 🔐 Admin Dashboard Features

### Authentication

* Secure admin login

### Product Management

* Add / edit / delete products
* Upload multiple images
* Set price, discount, stock
* Categorize products

### Order Management

* View all orders
* Update order status (pending, shipped, delivered)
* Customer details view

### Inventory Management

* Track stock levels
* Low stock alerts

### Analytics (basic)

* Total sales
* Orders count
